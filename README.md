# 📐 Polymath Zero (`polymath-zero`)
> **Plataforma Interactiva & Workbench de Fundamentos Matemáticos para Pre-Ingreso Politécnico & Carreras de Ingeniería.**

`polymath-zero` aborda la formación matemática pre-universitaria con el máximo estándar académico y formal, erradicando el cálculo mecánico ciego y priorizando el **razonamiento axiomático**, el **porqué de cada transformación algebraica**, y la **verificación computacional simbólica**.

---

## 🏛️ Filosofía Pedagógica: Del Axioma al Cálculo
1. **Razonamiento Teleológico (Por qué antes del Cómo):** Jamás se introduce una fórmula o algoritmo sin antes demostrar su necesidad ontológica.
2. **Canon Académico Directo:** Citas textuales de autores fundamentales de la literatura matemática:
   - *Michael Spivak* — Calculus
   - *Tom M. Apostol* — Mathematical Analysis & Calculus
   - *Gilbert Strang* — Linear Algebra and Its Applications
   - *Kenneth H. Rosen* — Discrete Mathematics and Its Applications
   - *Donald Knuth* — Concrete Mathematics
3. **Workbench de 5 Dimensiones:**
   - **Terminal REPL Simbólico:** Evaluación interactiva paso a paso.
   - **Demostración Formal:** Paso a paso axiomático justificado.
   - **Visualizador Geométrico:** Gráficos reactivos y espacios de funciones.
   - **Sondeo Socrático:** Preguntas a libro cerrado para forjar intuición profunda.
   - **Canon Académico:** Fundamento bibliográfico de cada concepto.

---

## 🚀 Inicio Rápido

```bash
# Instalar dependencias del workbench interactivo
npm install --prefix web

# Iniciar servidor de desarrollo en vivo
npm run dev

# Compilar para producción
npm run build
```

## 🗺️ Módulos Curriculares
- **Módulo 01:** Lógica Proposicional, Cuantificadores y Conjuntos Numéricos ($\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{C}$).
- **Módulo 02:** Álgebra Axiomática, Factorización y Fracciones Parciales sin Memorización.
- **Módulo 03:** Geometría Analítica, Vectores en $\mathbb{R}^2/\mathbb{R}^3$ y Trigonometría Circular.
- **Módulo 04:** Funciones Reales: Inyectividad, Sobreyectividad, Dominio Máximo y Continuidad.
- **Módulo 05:** Intuición Geométrica y Rigor del Concepto de Límite ($\varepsilon$-$\delta$).
